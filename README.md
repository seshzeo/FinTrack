# FinTrack

FinTrack — backend-приложение для учёта личных финансов. Позволяет управлять категориями доходов и расходов, создавать и редактировать финансовые операции, фильтровать историю операций и получать сводную статистику.

## Технологии

- Python 3.12
- FastAPI
- PyMongo с асинхронным API
- MongoDB
- Pydantic v2
- Uvicorn

## Реализованные возможности

### Категории
- Получение списка категорий.
- Создание пользовательских категорий.
- Переименование категорий.
- Удаление пользовательских категорий.
- Защита стандартных категорий от удаления.
- Проверка уникальности названий.

### Финансовые операции
- Создание, просмотр, редактирование и удаление операций.
- Поддержка доходов и расходов.
- Привязка операции к категории.
- Фильтрация по типу, категории и периоду.
- Поиск по описанию.
- Пагинация результатов.

### Статистика
- Общая сумма доходов и расходов.
- Расчёт баланса.
- Количество операций.
- Распределение доходов и расходов по категориям.
- Фильтрация статистики по периоду.

### Инфраструктура
- Асинхронное подключение к MongoDB.
- Автоматическое создание индексов.
- Инициализация стандартных категорий.
- Настройка CORS через переменные окружения.
- Проверка состояния приложения
