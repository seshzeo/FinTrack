# FinTrack

FinTrack — backend-приложение для учёта личных финансов. Позволяет управлять категориями доходов и расходов, создавать и редактировать финансовые операции, фильтровать историю операций и получать сводную статистику.

## Технологии

- Python 3.12
- FastAPI
- PyMongo с асинхронным API
- MongoDB
- Pydantic v2
- Uvicorn

## Реализованные возможности

### Категории

- Получение списка категорий.
- Создание пользовательских категорий.
- Переименование категорий.
- Удаление пользовательских категорий.
- Защита стандартных категорий от удаления.
- Проверка уникальности названий.

### Финансовые операции

- Создание, просмотр, редактирование и удаление операций.
- Поддержка доходов и расходов.
- Привязка операции к категории.
- Фильтрация по типу, категории и периоду.
- Поиск по описанию.
- Пагинация результатов.

### Статистика

- Общая сумма доходов и расходов.
- Расчёт баланса.
- Количество операций.
- Распределение доходов и расходов по категориям.
- Фильтрация статистики по периоду.

### Инфраструктура

- Асинхронное подключение к MongoDB.
- Автоматическое создание индексов.
- Инициализация стандартных категорий.
- Настройка CORS через переменные окружения.
- Проверка состояния приложения.

## Требования

- Python 3.12
- Установленный и запущенный MongoDB
- Git

## Установка и запуск

### 1. Создание виртуального окружения

Выполняй из корня проекта:

```powershell
python -m venv .venv
```

### 2. Установка зависимостей

Также из корня проекта:

```powershell
.\.venv\Scripts\python.exe -m pip install -r backend\requirements.txt
```

### 3. Настройка переменных окружения

Создай файл `backend/.env` на основе `backend/.env.example`. При необходимости укажи параметры подключения к MongoDB.

### 4. Запуск приложения

Перейди в каталог `backend`:

```powershell
cd backend
```

Запусти приложение из этого каталога:

```powershell
..\.venv\Scripts\python.exe -m uvicorn app.main:app --reload
```

### 5. Документация и проверка состояния

После запуска доступны:

- Swagger UI: http://127.0.0.1:8000/docs
- ReDoc: http://127.0.0.1:8000/redoc
- Проверка состояния: http://127.0.0.1:8000/health


## Основные API-маршруты

| Метод | Маршрут | Назначение |
|---|---|---|
| GET | `/api/v1/categories` | Список категорий |
| POST | `/api/v1/categories` | Создание категории |
| PUT | `/api/v1/categories/{category_id}` | Переименование категории |
| DELETE | `/api/v1/categories/{category_id}` | Удаление категории |
| GET | `/api/v1/transactions` | Список операций с фильтрами |
| POST | `/api/v1/transactions` | Создание операции |
| GET | `/api/v1/transactions/{transaction_id}` | Получение операции |
| PUT | `/api/v1/transactions/{transaction_id}` | Обновление операции |
| DELETE | `/api/v1/transactions/{transaction_id}` | Удаление операции |
| GET | `/api/v1/statistics/summary` | Сводная статистика |

## Конфигурация

Основные параметры задаются через переменные окружения:

- `APP_NAME` — название приложения.
- `APP_ENV` — окружение.
- `API_V1_PREFIX` — префикс API версии 1.
- `MONGODB_URI` — адрес подключения к MongoDB.
- `MONGODB_DATABASE` — имя базы данных.
- `CORS_ORIGINS` — разрешённые источники для CORS.
