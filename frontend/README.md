# FinTrack Frontend

Клиентская часть FinTrack на React и Vite. Интерфейс получает данные через REST API backend; прямого подключения к MongoDB из браузера нет.

## Требования

- Node.js 20 или совместимая версия
- npm
- Запущенный backend FinTrack

## Установка и запуск

Из каталога `frontend`:

```powershell
npm install
npm run dev
```

Откройте адрес, который Vite выведет в терминал (по умолчанию http://localhost:5173).

Чтобы открыть приложение с других устройств в локальной сети:

```powershell
npm run dev -- --host 0.0.0.0
```

Backend запускается отдельно. Инструкции находятся в [../backend/README.md](../backend/README.md).

## Настройка API

При необходимости создайте файл `.env` на основе `.env.example`.

- `VITE_API_URL` — базовый URL API. По умолчанию используется `/api/v1`; запросы проксируются Vite на локальный backend в режиме разработки.

## Возможности интерфейса

- Сводка доходов, расходов, баланса и количества операций.
- Визуализация расходов по категориям.
- Создание, редактирование и удаление финансовых операций.
- Поиск по описанию.
- Фильтрация операций по типу, категории и периоду.
- Пагинация списка операций.
- Создание, переименование и удаление пользовательских категорий.
- Отображение ошибок API и состояний загрузки.

## Технологии

React, JavaScript, Vite, CSS и Fetch API. Дополнительные UI-библиотеки не используются.
