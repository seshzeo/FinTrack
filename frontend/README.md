# FinTrack Frontend

Клиентская часть учебного проекта на React и Vite. Интерфейс обращается к существующему FastAPI API, а финансовые данные берёт из MongoDB через бэкенд.

## Запуск

1. Установите Node.js 20 или совместимую версию.
2. В этом каталоге выполните `npm install`.
3. При необходимости скопируйте `.env.example` в `.env` и измените `VITE_API_URL`.
4. Выполните `npm run dev` и откройте адрес, указанный Vite (по умолчанию http://localhost:5173).
5. Отдельно запустите FastAPI из каталога `backend`: `..\.venv\Scripts\python.exe -m uvicorn app.main:app --reload`.

## Возможности

- Сводка доходов, расходов, баланса и количества операций.
- Распределение расходов по категориям.
- Создание, редактирование и удаление операций.
- Поиск и фильтрация по типу, категории и периоду.
- Пагинация списка операций.
- Создание, переименование и удаление пользовательских категорий.
- Отображение ошибок API и состояний загрузки.

## Технологии

React, JavaScript, Vite, CSS и Fetch API. Дополнительные UI-библиотеки не используются.
